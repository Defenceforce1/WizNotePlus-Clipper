# WizNotePlus Clipper

为知笔记网页剪藏工具，支持 Apple Silicon Mac。当前版本 **1.0.0 正式自用版**，Safari 分享菜单名称为“为知笔记”。可独立保存网页到为知云端，无需启动主笔记客户端。

## 使用

将应用安装到“应用程序”。在 Safari 选择“分享 → 为知笔记”，登录账号、选择文件夹，上传正文或选中内容。支持修改标题与记住密码。上传需要联网；双击应用不显示启动窗口，属于正常行为。详见[使用说明](docs/USER_GUIDE.md)。

## 特性与边界

- HTML 笔记及图片，支持可静态保存的公式、代码着色、缩进与换行。
- 优先识别正文；主动选择按选区保留，公式按完整表达式处理。
- 密码仅保存在本扩展的本机钥匙串，不读取旧客户端凭据。
- 上传只提交一次；结果不明确时不自动重复上传，可在网页版检查。
- 复杂 SVG/canvas、受保护资源及部分网页排版可能无法完整保存。

用户已反馈另一台 Mac 安装使用及图标正常；本机 Safari 曾出现图标占位，根因未确认。不以单机通过保证全部系统或电脑兼容。

## 安装与签名

macOS14及以上，Apple Silicon。个人安装包使用已有 **Apple Development** 身份签名，**未经 Apple 公证，非为知官方发行**。免费开发签名不等于 Developer ID 分发；其他 Mac 的系统授权和加载需实际确认。不要求购买付费开发者计划，也不建议关闭系统安全保护。
