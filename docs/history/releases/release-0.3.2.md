# 0.3.2 — Wikipedia 正文、侧栏与底部清理

2026-10-15，内部版本 6。包含 0.3.1 的标题、自动结束分享、网页版按钮和机械图标留白处理；保留云端只推送，无结果轮询、不自动重复提交，不改主 App、旧官方剪藏器、身份和凭据服务。

## 修订范围

用户报告图片中的问题主要是网站侧栏和底部菜单，不是正文内容缺失；随后明确停止超理测试，只用提供的 [Wikipedia 样例](https://en.wikipedia.org/wiki/Homogeneous_polynomial)。本轮不再对超理作抓取／回放／上传测试，也不宣称已专门修复该站点。

- 优先识别 Wikipedia 文章容器，支持桌面 `.mw-parser-output`、旧 `#mw-content-text` 和独立 Parsoid body。跳过网站的头部／侧栏／底部外壳；清理文章内章节编辑控件、相关导航及其空包装、维护提示的装饰图标。保留维护提示本身，避免去除文章质量提示。
- 保留各正文分节、公式、图片、图注、表格、文章附注、参考文献和目标 ID。不通过一概删除所有列表／aside／footer 的方式清理，避免连正文引用和作者信息一起丢失。
- 根容器清除网站布局留下的 margin／padding／边框占位。来源链接与原网页许可文字另作紧凑段落保留，不携带页脚菜单、徽标及其布局。
- 其他页面优先单一语义 main；不明确时回退页面主体，不擅自只取多个 article 中的第一篇。没有通用正文识别成功的保证。
- “保存选中”不套用上述正文裁切，即使选区在侧栏，仍按用户主动选择保存。不改变页面 DOM，不改变原网页、既有笔记或已经剪藏的内容；只对重新剪藏生效。

## 实际验证与限制

本机共 121 项：输入 10、模拟云端／资源 36、只推送状态 10、原生分享表单 16、静态捕获 13、正文边界合成 22、机械图标 4、固定公开 Wikipedia HTML 本地回放 10，均通过。默认公开 CI 不含本机图标及下载的网页，执行 107 项。修订后重新运行签名、arm64、脚本与完整测试；不把本机结果说成远端 CI 已成功。

新增合成覆盖侧栏／页脚排除、正文图表和参考文献保留、下载清单不含网站徽标、选区不被裁切、空容器回退、多篇 article 不丢失、旧版／Parsoid 结构，以及装饰图标／空导航包装。实际公开网页另核对各章节、MathML 分数／幂次、注释／引用和许可仍在，站点菜单／底部徽标未进入输出；清理后的顶部与底部已渲染检查。

公开网页仅下载为本机样本，在 WebKit 阻断 HTTP(S) 资源的环境回放；外部 CSS／图片不加载，因此该检查验证正文边界和静态公式，不等同于 Safari 已加载样式的完全视觉复现。网页原文与衍生 HTML／截图留在忽略的 outputs，不公开，不上传为知账号。真实服务器是否采用编辑后的标题、实际分享关闭、资源下载及同步后的观感仍由用户试用确认。原有受保护资源、SVG／canvas、开发签名多机加载与系统图标底板限制不因本版消失。

用户已允许更新并确认退出 Safari。安装前仍复查进程，只替换独立剪藏器、完整保留已安装的 0.3.0 回退；本版未经公证。不操作真实账号，不强退其他程序、不改变系统保护，不动主 App 或笔记数据。
