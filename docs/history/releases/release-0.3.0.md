# 0.3.0 — 云端精简与推送流程修订

2026-10-15；内部版本 4，宿主／分享标识、云端凭据服务不变。用户授权继续剪藏器开发，移除本地连接、版式预览和内容摘要，并处理旧轮询／保真问题与优化界面；主 App 14.4.16 不动。

## 已实现

- 云端专用：删除本地配对 UI、连接码、loopback 客户端／模型、桥接 CLI、自有本地钥匙串读写及 ATS 本地网络例外，不只是隐藏菜单。不删除历史钥匙串项或旧客户端资料。
- 原生 460×340 表单，保留标题、账号／登录、文件夹、整页／选区、上传／取消。移除预览 WebView 和摘要控件；分享扩展不再链接 WebKit，宿主保留 WebKit 仅为本地合成捕获自测。浅色／深色语义配色，账号长名中间截断并保留 tooltip。
- 只推送、不查询：删除 status API、轮询、恢复／写入未确认任务及解除等待 UI。旧 UserDefaults 任务记录被忽略，不清理用户设置。有效 HTTP／API 接收回执即显示“服务器已接收，尚未确认最终保存”，可无任务 ID，不冒充完成保存。
- 单次操作最多一次 POST；发送中／已接收再次点击不重传。响应不明确显示错误并提示检查网页版，可关闭当前分享、继续下一次，不能把未确认误记成保存失败后自动重传。发送后关闭不能撤销服务器已接收的任务。
- 取消在资源处理完成前发生时不再上传；晚到回调不修改已结束分享。预处理错误在网络请求前返回，保留编辑和修正机会。
- 有语义 MathML 的 Wikipedia／MathJax／KaTeX 归并单层公式，移除重复后备图片和预览层，原生隐藏 MathML 正常化，隐藏跟踪图不进入下载清单。失败图片改为带简短 alt／“原图”的安全链接，不在每处插入长缺图文字；成功图片保留已清理尺寸、样式和 alt。
- 用户提供旧 App 图标用于本机；构建脚本可选配置 icns，但许可未确认，不提交或上传该资产，公开 CI 不带旧官方图标。未启动、修改或借用旧官方 App 身份／凭据。

## 验证与初次失败

本机最终候选 74 项：输入 10、模拟云端／资源 33、只推送状态／取消 10、真实分享表单结构 8、网络阻断 WebKit 捕获 13。检查涵盖无任务 ID、API 拒绝、响应不明确、同次重复点击、旧失败不阻止新分享、发送前取消／晚到回执、选区正文、MathML 去重、隐藏原生公式和图片回退安全。浅深色截图逐一查看，不登录或上传真实账号。

最终开发签名包另外通过 1 项固定上游公开 PNG 下载／解码／嵌入检查，沿用本机已有代理，不发送凭据、不改系统设置。合计 75 项；该单一公开资源检查不推广为所有图片成功，也不纳入默认 CI 联网流程。宿主／扩展均为 arm64，严格签名、图标配置及脚本／plist 语法通过。公开源码和默认 CI 不包含用户旧官方图标。

首次新增表单测试把文件夹 NSPopUpButton 当作普通操作按钮，导致精确操作按钮集合断言失败；已按控件实际角色区分，保留文件夹检查和断言。浅深色截图还暴露初稿使用已解析 CGColor 时背景不随外观变化，已改为 AppKit 语义颜色绘制；后续完整检查和截图通过。旧失败记录仅本机保留，不称首次即通过。

## 仍未验证／限制

不是全部网页保真修复：没有语义 MathML 的 SVG／canvas、受登录保护或不符合下载限制的图片、复杂站点 CSS 仍可能回退为链接。远程抓取仍遵循既有无凭据、限时限量、HTTPS／重定向／私网限制，不为支持图片降低安全检查。此前超理论坛真实页面及云端同步后效果仍需用户验证。

不代理用户登录／上传。服务器最终保存、账号权限兼容、客户端同步后的 HTML／公式／图片、凭据持久化和其他 Mac 开发签名加载没有本轮真实验收。免费 Apple Development 本机签名、未公证；不能推广为多机通用发行身份。保留完整 0.2.0 回退，更新前检查程序已退出，不强退、不覆盖旧官方 App 或重建主 App。
