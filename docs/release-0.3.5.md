## 本版范围

- 选择圆形剪刀 A：徽章直径41.4%，中心77.5%/77.0%（从左上计），原图素材不重绘。
- 用户明确批准原生分层路线。新系统按 CFBundleIconName=AppIcon 选择 Apple actool 编译的 Assets.car，保留独立背景/徽章组及材质属性，不把已烘焙玻璃的整张 PNG 当原生图层，也不再手工叠加那套外投影。实际视觉随系统、外观和显示位置变化。
- 旧系统按 CFBundleIconFile 使用已选 A 版高分辨率静态 ICNS 兼容图。它是旧系统回退，不是新系统的分层输入。
