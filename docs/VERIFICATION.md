# 验证范围

## 1.0.0正式自用版

本版整理显示名称、说明与发行流程，延续0.3.8的网页、公式、代码、账号和上传行为。分享名称为“为知笔记”。本机195项通过：构建/资源/模拟83，表单/合成捕获95，发行元数据/签名9，指定网页代码回放8。实际安装包校验见本机交付记录。

自动检查覆盖输入、模拟云端、登录续期、凭据注入、单次上传、取消、原生表单、安全清洗及正文/选区回归。指定网页仅回放两个代码块，逐字符比对换行与缩进；网络阻断，不登录或上传。

发行检查核对固定身份、版本、显示名、沙盒、arm64、签名及生产包隔离。自用交付另需检查开发签名身份一致，以及ZIP解压/DMG只读挂载后与正式包一致。

## 用户实测与限制

用户已反馈另一台Mac安装使用及图标正常，不代表全部硬件和系统已验证。本机曾显示占位图，根因未确定。

自动检查不读取真实密码/钥匙串，不验证云端最终保存或所有客户端同步后的显示；未来macOS与全部Mac不能仅凭本机测试作保证。开发签名不是Apple公证。

交付时未代为安装；用户随后自行安装，并明确授权纠正本扩展注册及关闭再开启开关。当前系统只指向Applications中的1.0.0、已启用，系统显示名正确；本机Safari实际菜单仍显示旧名称／占位图，尚未解决。详情见[维护状态](MAINTENANCE.md)。本次整理只做文件／签名／资源核对，不重新登录或上传，也不冒充重新完成全部功能验收。

历史检查数见[开发验证记录](history/verification/development.md)与[历史发行说明](history/releases/)。原始日志及网页样本仅本机保存。
