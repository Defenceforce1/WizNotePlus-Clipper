# 0.3.3 — 选区、网页版入口、记住密码与配套图标

2026-10-15，内部版本 7。保持只推送、不轮询、无本地连接；不改主 App 或笔记数据。

## 选区与界面

- 选区不再套用原网页 body 底色，清理普通文字的背景色；移除底色后避免深色页面的白字变成白底白字。保留代码／表格／语义 mark 本身有意义的背景；整页样式和选区边界不改变。
- 分享窗口左下角新增“为知笔记网页版”，与启动窗口入口统一打开用户指定的 `https://www.wiz.cn/xapp`。只在点击时打开默认浏览器，不带账号或令牌。
- 删减重复的无需主 App、协议／签名／开发验收等界面说明；保留登录、离线、错误和上传不明确的反馈。接收后仍立即结束分享，不冒充最终笔记已保存。

## 登录与隐私

原版“记住登录”只存令牌，不存密码；令牌不可用时不能凭空续期。本版按用户明确要求，提供默认勾选且可取消的“记住密码（仅存于本机钥匙串）”。仅登录成功才保存，密码使用独立固定服务、`WhenUnlockedThisDeviceOnly`、禁止 synchronizable，不写普通配置／日志或 Git。账号输入变化时清空另一账号预填密码；取消对话框清空临时输入。

有效令牌直接读取文件夹，不访问密码。读取文件夹遇到接口返回码 301 时，若有同一账号记住的密码，最多向既有固定 `https://note.wiz.cn/as/user/login` 重新登录一次，再读取一次文件夹。核对新旧 userID／userGuid／kbGuid 一致后才接受更新的令牌；缺密码、网络错误、其他服务错误、再次 301、账号变化或存储失败均停下并显示错误。截图中的 301 来自应用接口返回码，不等同于 HTTP 301 重定向，也不宣称无真实账号验证就证明唯一服务端原因。

上传笔记仍至多一次 POST：包括上传返回 301 或网络不确定时都不自动重发、不自动重复创建笔记。取消勾选并成功登录后移除本扩展保存的令牌与密码；部分保存失败也清除不一致状态并持续提示。不读取旧剪藏器、主 App 或浏览器凭据。

更新后首次仍需用户自行登录一次并勾选记住密码；旧版只有令牌，无法恢复以前从未保存的密码。系统钥匙串可能要求用户授权，不能承诺永不再提示密码；其他 Mac 需分别登录。

## 图标

用户已自行接受 Icon Composer 首次协议。保留蓝底／白 W／剪藏徽章的品牌构图，以可编辑 SVG 和原生 `.icon` 分层重建；没有 AI 生图，也没有将假高光烘焙进旧位图。Apple actool 生成现代 `Assets.car` 和兼容 ICNS，保留浅色、深色、着色、透明外观，深色剪刀单独加浅色填充提升对比。参考 [Apple Icon Composer 指南](https://developer.apple.com/documentation/xcode/creating-your-app-icon-using-icon-composer)。实际 Dock／分享菜单缓存显示仍需试用确认。

另生成主程序对应图标：相同蓝底／白 W、不带剪刀。只交付图标及编译资源，不修改主 App 包、签名或运行进程。原图和所有品牌衍生图／文档仅本机自用，未确认公开再分发许可，因此不提交或打入公开 CI。分层编译脚本可公开使用；没有本机图标时 CI 仍可独立构建。不要用 Finder 自定义图标写入签名包；集成主图标应在其下一次构建签名前进行。

## 检查与未验证部分

默认 135 项：输入 10、模拟云端／资源 36、内存凭据／续期 17、只推送 10、原生表单 22、静态捕获 13、正文与选区 27。本机另图标编译 2、固定 Wikipedia 本地回放 10，合计 147 项。覆盖记住／不记住／存储部分失败、账号隔离、有效令牌、一次续期、重复 301／离线／其他错误不循环、上传 301 不重发、底部入口位置和选区去底色。主程序图标单独编译；两套外观预览已查看。

没有自动读取真实钥匙串、保存真实密码、登录账号或向用户云端提交测试笔记。记住密码的实际系统授权与跨分享重启、301 的真实续期、最终服务器保存／同步显示、Dock 图标缓存及多机开发签名仍需用户试用。安装前复查进程并保留完整 0.3.2 回退（含用户自定义图标），不强退、不过度清除系统属性；主 App 14.4.16 保持不变。历史说明不追改。
