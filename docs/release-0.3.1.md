# 0.3.1 — 标题、自动结束分享、网页版入口与图标尺寸

2026-10-15，内部版本 5；保留云端精简、不轮询、不自动重复上传及现有标识／云端凭据服务，不改主 App。

## 修订

- 上传按钮先结束原生标题字段的正在编辑状态，再取得最终文本并固定用于异步上传；标题同时写入原 gather 的 Base64 `param-title` 和 HTML `<title>`，后者转义 `&<>`，防止标题破坏文档或注入脚本。用户报告服务器最终标题不变；本轮补齐这两处客户端路径，不宣称未经云端实测就独立证明服务端故障的唯一原因。
- HTTP／API 接收后立即完成分享请求，移除原三秒延迟和所有“关闭”按钮文案，不等待最终保存。上传前仍可取消；回执不明确仍显示错误与取消，不冒充成功后悄悄关闭。结束请求与重复动作有一次性保护。
- 剪藏器启动说明窗口新增“打开网页版”，仅在用户点击时交给默认浏览器打开固定 `https://note.wiz.cn/`，不携带账号、令牌或密码，不自动登录或打开网页。
- 用户明确选择“原图保留、不用 AI 重绘，程序调整透明留白／大小／多尺寸”。打包时从忽略的本机 ICNS 原图生成十种 16—1024 像素表示，图案最大边取画布 82% 并透明居中；不改变原始文件，不画灰色底板。这是本项目的视觉尺寸选择，不是 Apple 强制比例，也不能证明系统自己的灰底／玻璃处理被取消。衍生图与旧图标不上传 GitHub。

## 验证

默认 85 项：输入 10、模拟云端／资源 36、只推送状态 10、实际表单／标题与启动入口 16、网络阻断捕获 13。本机带原图时额外 4 项机械图标检查；共 89 项。实际按钮测试在原生 field editor 中输入中文／特殊字符，不提前给控件 setText，点上传后核对元数据与 HTML 都是改名值、完成分享立即且仅一次、没有关闭按钮、重复动作不重发。网页版入口测试核对真实按钮／目标／action 与固定无令牌 URL，不实际打开用户网页或读取账号。

不登录真实账号或上传用户网页。真实服务器是否采用改名、实际 Safari 分享关闭、默认浏览器打开及系统 Dock／访达图标观感仍需用户试用确认；原有复杂网页／纯 SVG／canvas／多机开发签名限制不因本版消失。图标资源及自己的透明画布可检查，但不能以此保证 macOS 不再额外套底板。

完整自用开发签名、未公证；更新前再检查退出状态，保留完整 0.3.0 回退。图标、截图、原始日志／账号／证书不公开。原图标工具首次许可没有代为接受，本轮只使用已安装系统工具作机械处理，不改变许可同意标记或系统保护。

参考背景：[Apple 图标设计说明](https://developer.apple.com/design/human-interface-guidelines/app-icons/)说明系统图标遮罩／外观，[Icon Composer 文档](https://developer.apple.com/documentation/xcode/creating-your-app-icon-using-icon-composer)介绍现代多层图标；它们不证明用户这张截图的灰底唯一原因。本轮没有导入或编译现代 Composer 图标。
