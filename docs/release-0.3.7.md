# 0.3.7 — 选区公式与代码

2026-10-15，build13；个人自用开发签名，未公证。

## 修正

- 原先对选区只调用Range.cloneContents，副本脱离原文后无法读取样式表和对应MathJax实例，选区还可能只含公式渲染的一小部分。
- 新实现只遍历选中交集，保留到原始已连接DOM的WeakMap；普通文字严格截取首尾，不扩大到整段或整帖。公式视作完整表达式，保留同组语义MathML，避免分母、指数及辅助层被选择边界切掉。仍不修改源网页或上传公式到第三方转换服务。
- 选中代码保留选中的换行、空格和制表符，不擅自包含未选中的行。pre/code使用等宽字体、稳定行距与制表宽度，长行可折行；源样式表里的标记颜色通过原节点映射保留，深色代码有不透明可读画布。普通选中文字不恢复选中底色。整页代码也使用这些排版规则。
- 没有增加完整TeX编译器、MathJax运行库或额外联网依赖。复杂的纯SVG/canvas公式、缺失语义层且不能通过页面现有MathJax提取的公式仍可能退化；不承诺所有网站都无损。
