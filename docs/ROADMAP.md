# 维护范围

1.1.0以现有独立网页剪藏功能收尾，不增加新功能。

后续按实际反馈维护网页兼容性、图片/公式/代码保真、账号接口及macOS兼容性。保留单次推送、个人文件夹、选区与记住密码行为。

暂不加入多账号、私有服务器、标签/备注、离线队列或本地主App配对。剪藏器与主程序独立维护，主程序及其原版图标不变。

本机1.1.0正式安装版的Safari分享名称和图标已通过实际菜单观察。新的正式内部标识从此固定；不因普通更新反复换身份，不把这次绕行等同于已确定缓存根因，也不保证以后换图自动刷新。详情见[维护状态](MAINTENANCE.md)。

旧应用由用户自行删除。后续只在有具体问题时继续修订；不得为小图标问题自动清理全系统缓存、创建系统用户或关闭安全保护。
