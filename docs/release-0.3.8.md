## 根因与修订

源站使用PRE内的块级CODE，CODE自带1px dashed边框、6.8px内边距和黑色高亮背景。旧剪藏保存边框却遗漏display:block，因此CODE退为行内元素，边框沿多行片段反复绘制。0.3.7还统一了代码字号、字体及行距，导致观感变化。

- PRE承担一份背景及内边距；CODE清除装饰边框和重复内边距，明确为块级。安全清洗只为CODE允许display:block，不放开任意display值。
- 原网页已提供等宽字体时优先保留；字号与行距不强制覆盖。不可用的网页字体回退本机字体，不下载字体。
- 两个代码块均逐字符检查原文、换行和缩进，保留原语法着色。新增六项合成回归及八项本机代码专用回放。
- 使用相同代码样本运行0.3.7页面脚本，四项检查失败，复现逐行虚线、字体覆盖及代码画布问题；修订脚本相应检查通过。网页代码与截图仅留本机，不提交公共仓库。
