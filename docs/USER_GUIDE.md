# 为知笔记网页剪藏

版本1.1.0 · Apple Silicon · macOS14及以上

## 安装与更新

将 `WizNotePlus Clipper.app` 拖入“应用程序”。以后更新前请关闭剪藏窗口并正常退出 Safari，再替换同名应用。不要保留多份运行副本。

从1.0.0升级时，新版被系统视为独立应用：请重新启用分享扩展并登录。旧版 `WizNotePlus Web Clipper.app` 可由你自行删除；不要删除主笔记App或笔记资料库。新版不读取、导入或删除旧版保存的账号信息。

## 保存网页

1. Safari打开网页，选择“分享 → 为知笔记”。
2. 首次使用时登录为知账号，选择文件夹。
3. 按需修改标题，选择“保存整页”或“保存选中”，点击“上传”。

保存选中内容前先在网页选中文字。整页模式优先保存正文，不是网页截图。上传后通过为知客户端同步查看，也可点击窗口左下角“为知笔记网页版”。

开发版修复（尚未交付）：获取账号目录前，文件夹留空且不能上传；获取成功后只显示账号中已有的目录，并选中第一个。不会额外添加或固定选择“网页剪藏”；目录获取失败或为空时也不会补建文件夹。

## 登录与隐私

“记住密码”仅使用本机系统钥匙串，不通过 iCloud 同步。取消勾选并成功登录后，清除本扩展保存的登录信息。换电脑需独立登录。

## 常见问题

- **双击没有窗口：** 正常。请从Safari分享菜单使用，不需要启动主笔记App。
- **没有分享入口：** 在系统设置中找到扩展的分享菜单设置并启用本应用；位置随macOS版本变化。
- **有两个“为知笔记”：** 可能同时启用了旧剪藏器，可在系统扩展设置中停用旧入口。
- **上传结果不明确：** 先在网页版检查，避免重复保存。工具不会自动重传。
- **个别排版有差异：** 复杂或受保护资源可能无法静态保存，请保留原网页链接。

上传需要联网，但不要求安装主笔记客户端。修订只影响新剪藏，旧笔记不会自动重排。
