# 1.1.0正式自用版

2026-10-16 · build19

- 新的固定正式身份：`io.github.defenceforce1.wiznoteplus.webclipper` 与 `.share`；不是测试或临时标识，后续版本沿用。
- 英文应用文件名统一为 `WizNotePlus Clipper.app`；显示名仍为“为知笔记网页剪藏”，分享菜单仍为“为知笔记”。
- 保留批准的圆形剪刀A图形、原生宿主图标目录及小尺寸分享图标，不重绘原始素材。
- 新身份使用独立的本机登录存储，首次需重新启用扩展并登录；不读取旧凭据，不改变服务器账号或既有笔记。
- 不改正文/选区、图片、公式、代码和单次上传行为；不改主笔记App。
- 构建先完成装配和签名再进入最终输出路径；生产资源白名单拒绝废弃图标、测试工具及额外运行库。

完整新身份对照曾在本机Safari显示正确图标，旧身份仍占位；旧身份清理、重装和重启没有解决。采用新身份是经用户授权的绕行方案，不等同于已确定某个系统缓存缺陷，也不保证未来换图刷新或所有Mac兼容。

使用已有Apple Development身份进行个人开发签名，未经Apple公证，非官方发行。保留1.0.0回退；旧安装应用由用户自行删除，不自动卸载其他应用。
