## 用户提出的制作路线

1. 用 iconutil 解开本地授权使用的旧 ICNS，检查最大实际尺寸，不假定一定存在 1024 像素版本。
2. 尽量保留原图构图，不再凭印象重画 W 和剪刀。将 PNG 导入 .icon；包内 Assets/icon.json 可以生成，但需用本机 Composer/渲染工具验证，不能只验证 JSON 语法。
3. 本机 Xcode 内 ictool 版本 27.0，帮助中支持 --export-image、--platform、--rendition、--width、--height、--scale 和 --design-generation 26/27。可用于生成外观预览及静态输出。
4. 824 像素只是可尝试的视觉占比，不是 Apple 规定值；应按源图已有留白调整，避免重复缩小、重复圆角、重复阴影和灰边。
5. sips 可缩放/扩展画布，但其 pad 参数没有明确保证透明填充；不要将白色/灰色填充误当透明。检查角落 alpha，必要时沿用现有 AppKit 透明画布处理。
6. iconutil 可将标准多尺寸 iconset 打包为静态 ICNS；由 ictool 烘焙后再打包不会保留实时 Liquid Glass 外观适配。需要真正原生外观时，保留 .icon 并由 Apple 资产编译器编译，另保留 ICNS 兼容资源。
